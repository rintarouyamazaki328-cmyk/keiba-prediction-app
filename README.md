# 競馬予想アプリ

本格的な競馬予想Webアプリケーション。画像OCR機能、予想管理、点数計算、収支管理などの機能を備えています。

![競馬予想アプリ](./screenshot-placeholder.png)

## 主な機能

### 🖼️ 画像OCR機能
- 画像アップロード（ファイル選択、ドラッグ&ドロップ、クリップボード貼り付け）
- Tesseract.js を使用した日本語OCR
- 画像の前処理（コントラスト強調、グレースケール化）で精度向上
- 読み取り結果の編集・修正機能
- 馬名・騎手名の自動抽出
- 読み取り信頼度の表示

### 🏇 レース情報管理
- 日付選択
- 競馬場選択（京都、東京、阪神、中山、中京、小倉、新潟、福島、札幌、函館）
- レース番号（1R〜12R）
- レース名入力
- 楽天競馬・netkeiba・JRA公式へのクイックリンク生成

### 🐴 出走馬管理
- 馬の追加・編集・削除
- 各馬の情報：枠番（1〜8）、馬番、馬名、騎手名、脚質、単勝オッズ
- 脚質タイプ：逃げ（赤）、先行（オレンジ）、差し（青）、追込（紫）
- 枠番カラー対応
- クイック入力（CSV形式でまとめて追加）
- オッズ順・馬番順ソート
- 脚質フィルタリング

### 🎯 予想機能
- 三連単予想（1着・2着・3着を順番通りに選択）
- 三連複予想（3着以内の3頭を選択、順不同）
- 複勝予想（3着以内に入る馬を1頭選択）
- 選択した馬のハイライト表示（金・銀・銅の枠）
- 予想の保存機能

### 🧮 点数計算機能
- ボックス買い計算
- フォーメーション計算
- ながし計算
- 券種選択（三連単、三連複、馬連、ワイド）
- 1点あたり金額設定
- 購入点数・合計金額の自動計算

### 📊 履歴・収支管理
- 予想履歴の保存（LocalStorage）
- 結果入力（的中/不的中）
- 払戻金入力
- 統計表示：予想回数、的中数、的中率、回収率

### 🎨 UI/UX
- レスポンシブデザイン（モバイル対応）
- ダークモード対応
- 競馬らしいカラースキーム（緑・ゴールド系）
- shadcn/ui コンポーネントの活用
- ローディング状態の表示
- トースト通知

## 技術スタック

- **Next.js 14** (App Router)
- **TypeScript**
- **Tailwind CSS**
- **shadcn/ui** (UIコンポーネント)
- **Zustand** (状態管理)
- **Tesseract.js** (ブラウザOCR)
- **next-themes** (ダークモード)

## セットアップ手順

### 必要条件

- Node.js 18.17 以上
- npm または yarn

### インストール

```bash
# リポジトリをクローン
git clone https://github.com/your-username/keiba-prediction-app.git
cd keiba-prediction-app

# 依存関係をインストール
npm install

# 開発サーバーを起動
npm run dev
```

ブラウザで [http://localhost:3000](http://localhost:3000) を開いてアプリケーションを確認できます。

### ビルド

```bash
# プロダクションビルド
npm run build

# プロダクションモードで起動
npm start
```

## 使い方ガイド

### 1. OCR機能を使う

1. 「OCR」タブを選択
2. 画像をアップロード（ドラッグ&ドロップ、ファイル選択、またはクリップボードから貼り付け）
3. 「OCR実行」ボタンをクリック
4. 読み取り結果を確認・編集
5. 「馬を追加する」ボタンで出走馬リストに追加

### 2. レース情報を設定

1. 「レース」タブを選択
2. 日付、競馬場、レース番号、レース名を入力
3. 必要に応じてクイックリンクから公式サイトを確認
4. 出走馬を追加・編集

### 3. 予想を入力

1. 「予想」タブを選択
2. 予想タイプを選択（三連単、三連複、複勝）
3. 馬を選択
4. 「予想を保存」をクリック

### 4. 点数を計算

1. 「計算」タブを選択
2. ボックス、フォーメーション、ながしから選択
3. 券種を選択
4. 馬を選択
5. 1点あたりの金額を入力
6. 自動計算される点数と金額を確認

### 5. 履歴を確認

1. 「履歴」タブを選択
2. 統計情報を確認
3. 予想結果を入力（的中/不的中）
4. 払戻金を入力
